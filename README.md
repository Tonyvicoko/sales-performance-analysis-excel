# Sales Performance Analysis Dashboard – Excel

## Executive Summary

This project was completed as part of my Data Analytics training with TS Academy.

The objective was to analyze a sales dataset using Microsoft Excel and transform the raw data into meaningful business insights through data preparation, KPI calculations, PivotTables, data visualization, and an interactive dashboard.

The analysis focuses on revenue, cost of goods sold (COGS), profit, customer transactions, product performance, sales representative performance, city-level costs, and monthly transaction trends.

## Key Performance Indicators

| KPI | Result |
|---|---:|
| Total Revenue | ₦2,328,370,000 |
| Total COGS | ₦1,862,696,000 |
| Total Profit | ₦465,674,000 |
| Customer Transactions | 2,098 |

## Key Insights

- Laptop A13 generated the highest profit among the products analyzed.
- Peter generated the highest revenue among the sales representatives.
- Lagos recorded the highest COGS among the cities analyzed.
- May recorded the lowest number of transactions in the available dataset.
